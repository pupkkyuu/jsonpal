# JSONPal 功能与 UI 迁移说明

本说明是迁移前 Electron 版本（`35dc042`）的历史功能基线，依据当时源码及 `docs/images` 中的界面截图整理；未运行应用做动态验收。MyGo Demo 的当前功能和开发方式见根目录 `README.md`，暂缓功能见 `TODO.md`。下文的源码路径属于旧版，可从 Git 历史查看。

## 1. 产品与页面

JSONPal 是本地桌面 JSON 工具，包含多标签工作区、JSON 编辑与处理、双栏文本差异对比、搜索及编辑器设置。

- 当前技术：Electron、TypeScript、React、Monaco Editor、Zustand、Tailwind CSS。
- 三种主视图：普通 JSON 编辑、双栏对比（输入/对比两种模式）、设置。
- 设置在主窗口右侧工作区内打开，左侧标签栏继续保留；返回后继续原编辑会话。
- JSON 处理和编辑器资源均在本地运行，不需要远程服务。
- 打包目标：macOS DMG/ZIP，Windows 安装版/便携版，Linux AppImage/tar.gz。README 标明仅在 macOS 经过测试。

## 2. 整体功能清单

### 2.1 标签与工作区

| 功能 | 当前行为 |
| --- | --- |
| 新建格式化 | 新建普通 JSON 标签并激活；初始标签为“格式化 1”，带示例 JSON；后续新标签为空 |
| 新建对比 | 新建左右两个输入编辑器的对比标签并激活 |
| 标签命名 | 自动编号；普通和对比标签共用递增计数器 |
| 切换 | 点击标签或使用快捷键；活动标签在列表外时自动滚动到可见位置 |
| 重命名 | 双击标题进入输入；Enter/失焦提交，Esc 取消；去除首尾空白，空名称不提交 |
| 排序 | 支持鼠标拖动及键盘拖动，垂直排序 |
| 关闭 | 悬停/聚焦时显示关闭图标；右键提供关闭当前、关闭其他、关闭所有 |
| 最后一个标签 | 关闭后自动创建空白普通标签，工作区始终至少有一个标签 |
| 关闭活动标签 | 优先激活关闭位置的下一个标签；末尾关闭时激活前一个 |
| 标签状态 | 会话内保留内容、编辑器视图和撤销历史；搜索状态按标签保留；对比视图保留两侧焦点、选区与滚动位置 |
| 侧栏开关 | 收起到宽度 0；收起后工具栏左侧提供展开按钮 |
| 侧栏尺寸 | 默认 180px，范围 160–420px；拖动边界调整，键盘左右方向键每次调整 10px；同时尽量给右侧留出 400px |

### 2.2 JSON 编辑与处理

| 功能 | 当前行为 |
| --- | --- |
| 编辑 | JSON 语法高亮、行号、括号匹配、缩进引导、折叠、缩略图等由编辑器提供 |
| 基础操作 | 剪切、复制、粘贴、全选、撤销、重做；自定义右键菜单只有剪切/复制/粘贴 |
| 校验 | 编辑时读取 JSON 诊断；普通编辑器标出错误行、左侧红色标识和滚动概览中的错误位置 |
| 格式化 | 调用编辑器文档格式化能力，默认 2 空格缩进 |
| 压缩 | 严格解析 JSON 后重新序列化为紧凑文本 |
| 按字段排序 | 递归排序对象键，2 空格输出；数组顺序保持不变，数组中的对象也递归处理 |
| 转义 | 将整段输入文本序列化成 JSON 字符串，包含外层双引号；不要求原输入是有效 JSON |
| 去除转义 | 优先解析完整 JSON；失败后尝试把输入当作没有外层引号的转义字符串解析；仅当解析结果是字符串时替换文本 |
| 去除转义边界 | 一次操作解除一层；已解析为对象/数组等非字符串时不改动；解码后可以是非 JSON 普通文本 |
| 复制全部 | 普通标签复制完整编辑器文本；右键复制遵循编辑器当前选区行为 |
| 清空 | 清空文本；通过编辑操作提交，可撤销 |
| 全部折叠/展开 | 批量改变折叠状态 |
| 自动换行 | 工具栏切换；属于全局编辑器设置，立即应用并保存 |

压缩、排序和显式校验使用严格 JSON 解析。格式化使用编辑器服务，不能把它视为同一套解析器。变换在后台 Worker 中执行；应用结果前确认标签、模型和版本仍有效，防止覆盖新输入。格式化以外的内容替换进入撤销栈。

### 2.3 双栏对比

| 功能 | 当前行为 |
| --- | --- |
| 输入模式 | 左右两个可编辑 JSON 编辑器，水平等分，分别维护文本 |
| 对比开关 | 工具栏在“对比 JSON”和“编辑 JSON”之间切换，复用原文本模型 |
| 比较方式 | 使用编辑器文本差异算法；进入对比时不会自动格式化或排序，也不进行独立的 JSON 结构语义比较 |
| 差异显示 | 并排显示行及行内差异，删除部分为红色、增加部分为绿色；右侧提供差异概览 |
| 差异导航 | 对比模式出现上一个/下一个差异按钮 |
| 对比中编辑 | 左右两侧仍可编辑，差异结果随文本更新 |
| 工具可用性 | 对比模式禁用格式化、压缩、转义、去转义和排序；复制、折叠、换行、搜索、清空仍可用 |
| 双侧格式化 | 输入模式中逐侧校验并格式化；一侧非法时该侧跳过，另一侧仍可能格式化 |
| 双侧变换 | 输入模式中压缩/排序/转义/去转义对两侧执行，空侧跳过；先计算所有结果，任一侧失败时不提交这些变换 |
| 双侧复制 | 工具栏复制将左文本、换行、右文本拼接写入剪贴板 |
| 双侧折叠 | 全部折叠/展开同时作用于两侧 |
| 清空 | 清空两侧并返回输入模式，重置视图位置，焦点回到左侧 |
| 视图连续性 | 模式切换及标签切换时保留焦点、选区、滚动与搜索状态；过渡层避免编辑器切换闪烁 |
| 尺寸限制 | 固定左右各 50%；中间分隔不可拖动；窄空间也维持并排，不切换为内联差异视图 |
| 缩略图 | 输入模式遵循全局设置；对比模式关闭缩略图，保留差异概览 |

### 2.4 搜索

- 通过工具栏或 Ctrl/Cmd+F 打开，浮在编辑器上方，不挤压编辑区。
- 支持区分大小写、全字匹配、正则表达式。
- 高亮匹配结果，显示当前位置/总数，支持上一个、下一个以及循环跳转。
- Enter 查找下一个，Shift+Enter 查找上一个，Esc 关闭。
- 单行选区可自动作为搜索词；关闭搜索后返回编辑器焦点。
- 非法正则表达式显示错误提示；最多统计 10,000 个结果，搜索更新防抖 100ms。
- 对比标签统一搜索左右两侧，共享条件和计数，结果按左侧再右侧合并。
- 当前自定义搜索面板提供查找功能，没有替换输入或替换按钮。

### 2.5 设置与持久化

设置修改立即生效，约 300ms 防抖后写入应用用户数据目录中的 `editor-settings.json`。配置读取失败时使用默认设置；保存失败时设置页顶部显示错误。设置加载时对类型、枚举和数值范围做校验。

| 设置 | 默认值 / 范围 | UI 位置 |
| --- | --- | --- |
| 缩略预览 | 开启 | 显示 |
| 缩略预览字符 | 关闭；缩略预览关闭时此开关禁用 | 显示 |
| 粘滞滚动 | 开启 | 显示 |
| 代码折叠 | 开启 | 显示 |
| 空白字符 | 边界显示；可选不显示/边界/全部 | 显示 |
| 括号配对着色 | 关闭 | 编辑行为 |
| 括号缩进引导线 | 开启 | 编辑行为 |
| 行号 | 绝对；可选绝对/相对 | 编辑行为 |
| 粘贴时格式化 | 关闭 | 编辑行为 |
| 可疑 Unicode 高亮 | 关闭 | 辅助功能 |
| 字体大小 | 14px；12–24px | 辅助功能 |
| 滚动条宽度 | 12px；8–20px | 辅助功能 |
| 自动换行 | 关闭 | 编辑器工具栏 |

设置页另含配置路径、快捷键说明和关于信息。配置路径支持展开完整路径、复制路径、打开所在文件夹；关于信息显示版本和作者邮箱。

持久化范围仅为上述编辑器设置。标签名称/顺序/内容、活动标签、搜索条件、编辑器视图、侧栏宽度/折叠状态均只在当前会话内保留，重启不会恢复。

### 2.6 桌面集成与异常状态

- 初始窗口 1000×650，最小 760×520。
- macOS 顶部保留系统三色按钮；侧栏收起后右侧工具栏为其留出空间。
- Windows/Linux 顶部额外提供约 32px 的系统窗口控制叠加栏，颜色与侧栏一致。
- 标题栏/工具栏空白区域可拖动窗口，交互控件排除拖动。
- 原生菜单包含编辑操作、关闭/退出、关于等平台功能；Windows/Linux 隐藏菜单栏但保留原生命令快捷键。
- 编辑器加载中显示居中转圈和“正在加载编辑器”；资源加载失败显示错误说明及重试按钮。
- Ctrl/Cmd+R 被拦截以避免刷新导致会话丢失；HTTP/HTTPS 新窗口链接交给系统浏览器。
- 图标按钮带中文提示与部分快捷键提示，支持键盘焦点；减少动态效果偏好会关闭部分动画。

## 3. UI 布局描述

### 3.1 主界面

```text
┌──────────────────┬──────────────────────────────────────────────┐
│ 窗口控制 / 收侧栏 │ 当前标签名           操作图标组  搜索 / 清空 │
├──────────────────┼──────────────────────────────────────────────┤
│ ＋ 新建格式化     │                                              │
│   新建对比       │  普通标签：单个 JSON 编辑器                   │
│                  │  对比标签：左侧编辑器 │ 右侧编辑器            │
│ 标签页（数量）   │                                              │
│ [活动标签]       │  行号、折叠区、JSON 文本                      │
│ [其他标签]       │  右侧缩略图 / 差异概览、滚动条                │
│ …列表独立滚动    │  搜索面板浮在编辑区域右上方                   │
│                  │                                              │
│ ⚙ 设置           │                                              │
└──────────────────┴──────────────────────────────────────────────┘
```

- 左侧栏固定布局、可调整宽度；顶部为 56px 标题区，接着两个 40px 高的新建入口。
- 中间是“标签页（数量）”标题和可滚动列表；标签高 40px、圆角 8px，活动项灰色填充；关闭按钮悬停/聚焦出现。
- 底部为固定 48px 高设置入口。
- 右侧工具栏高 52px，标题左对齐、超长省略；操作区靠右，图标 28×28px，灰色圆角胶囊分组。
- 工具栏操作顺序：格式化、压缩、对比开关（对比标签才有）｜折叠、展开、换行｜转义、去转义｜复制、排序。末尾另组搜索、清空。
- 对比模式在主操作区之前增加独立的上/下差异按钮组。
- 编辑区域占满余下高度。默认等宽字体 14px、行高 23px、缩进 2 空格，白色背景、左侧行号、右侧缩略图与滚动条。
- 对比输入模式右侧预留 30px，与结果模式的差异概览宽度对应，尽量保持两种模式栏位对齐。
- 侧栏收起/展开约 200ms；编辑器随可用区域重新布局。850px 以下工具栏缩小部分间距，未实现移动端导航布局。
- 当前主编辑页无底部状态栏。

### 3.2 搜索浮层

- 单编辑器中距编辑区域顶部和右边各 8px，最大宽度 280px；对比视图的放置结合右側编辑器尺寸调整。
- 第一行是搜索输入；分隔线下是大小写/全字/正则开关、结果计数、上下导航和关闭。
- 可用宽度较小时缩小按钮和计数文字；打开/关闭使用约 160ms 动画。

### 3.3 设置页

- 使用主界面同一侧栏，替换右侧内容；顶部工具栏包含返回箭头、“设置”和保存错误信息。
- 下方内容纵向滚动，居中单列，最大宽度 576px，左右内边距 24px，上下内边距 32px。
- 顺序为配置文件路径、显示、编辑行为、辅助功能、快捷键说明、关于 JSONPal。
- 各组标题下为白色卡片，圆角 12px、细边框、内边距 20px/24px；设置行左侧图标和名称，右侧开关、下拉框或滑块。

## 5. 当前功能边界与迁移注意事项

- 未实现文件打开/保存/导入/导出、拖入文件、会话自动恢复、云同步、账号系统、JSONPath、Schema 管理或 JSON/YAML/XML 互转等产品入口。
- 查找面板没有自定义替换 UI；不可把编辑器库潜在能力直接计入已设计的产品功能。
- 状态对象记录“JSON 有效”、错误行列、复制成功等信息，但主界面没有统一渲染这些文案的状态栏或通知组件；普通编辑器错误行装饰和编辑器诊断仍可见。
- 对比是文本差异。若迁移后增加结构化比较、自动排序或自动格式化，会改变当前交互语义。
- JSON 变换使用 JavaScript `JSON.parse/stringify`：大整数存在精度限制，重复键按解析器规则合并，类似整数的对象键受 JavaScript 枚举顺序影响。其他语言若保留任意精度、原始数值文本或重复键，结果可能不同，应明确兼容目标。
- 字段排序按 JavaScript 字符串顺序进行，不是拼音或自然排序；数组顺序保持不变。
- 转义处理应保留外层引号、一层解码及非 JSON 解码结果的行为。
- 保留独立文档模型与撤销栈、双侧变换失败不部分提交、异步结果版本校验、编辑器视图恢复及后台执行，以维持目前交互。
- 可按六个模块迁移：桌面窗口服务、工作区/标签、编辑器适配、JSON 处理、差异/搜索、设置持久化。编辑器复杂交互是主要迁移工作量。
