# JSONPal 快捷键

适用于当前 macOS 原生版本。编辑器快捷键沿用项目固定依赖的 MyGo v0.4.8；应用快捷键由 JSONPal 工作区处理。

## 按键说明

| 符号 | 按键 |
|---|---|
| `⌘` | Command |
| `⌃` / Ctrl | Control，与 Command 不同 |
| `⌥` | Option |
| `⇧` | Shift |

表中的“再按”表示组合快捷键：完成第一组按键并松开，再输入第二组。例如 `⌘K`，再按 `Z`，第二步不需要按住 Command。

## 应用与标签页

| 快捷键 | 功能 |
|---|---|
| `⌘N` | 新建并聚焦空白格式化标签 |
| `Ctrl+Tab` | 按侧栏顺序切换到下一个标签 |
| `Ctrl+Shift+Tab` | 按侧栏顺序切换到上一个标签 |
| `⌘B` | 收起 / 展开侧边栏，保留已调整的宽度 |
| `⌘,` | 打开设置 |
| `Esc` | 关闭设置面板 |
| `⌘⇧F` | 格式化当前文档；对比输入模式下同时格式化两侧 |

标签切换采用侧栏排列顺序，末尾与开头循环衔接，同时支持格式化和对比标签。切换后聚焦目标编辑器，并保留文档、选区、撤销记录及对比模式；没有标签或只有一个标签时保持原样。设置面板打开时暂停新建、切换标签和侧边栏收起/展开快捷键。

差异预览为只读，`⌘⇧F` 不执行格式化。

有对应快捷键的按钮会在 tooltip 中显示提示。组合键用 `→` 表示先后顺序，例如“全部折叠（⌘K → ⌘0）”。提示随编辑器模式变化：差异预览不显示输入模式的换行快捷键，对比的双侧折叠/展开也不标注仅作用于单侧的原生快捷键。工具栏全文复制与 `⌘C` 的选区复制行为不同，因此不会标注 `⌘C`。

## 查找与定位

以下快捷键需要焦点位于编辑器或其查找输入框。

| 快捷键 | 功能 |
|---|---|
| `⌘F` | 打开查找；在差异预览中返回输入模式并查找 |
| `⌘⌥F` 或 `⌘⇧H` | 打开查找替换 |
| `⌘G` / `⌘⇧G` | 下一个 / 上一个搜索结果 |
| `⌘E` | 使用选中文本作为查找内容 |
| `⌘⌥L` | 切换在选区内查找 |
| `⌃G` | 跳转到指定行 |
| `⌃L` | 将光标所在行滚动到视图中央 |
| `⌘⇧\` 或 `⌃M` | 跳转到匹配括号 |
| `Esc` | 关闭查找等编辑器浮层，或取消当前编辑器操作 |

对比输入模式的原生编辑快捷键作用于当前聚焦的一侧，两侧分别保存查找状态。

查找框中 `Enter` / `⇧Enter` 跳到下一个 / 上一个结果，`⌥Enter` 选择所有结果；替换框中 `Enter` 替换当前结果，`⌘Enter` 全部替换。查找栏按钮的 tooltip 也会显示相应快捷键。

## 编辑、行操作与缩进

以下修改操作适用于可编辑区域；只读差异预览不允许修改文档。

| 快捷键 | 功能 |
|---|---|
| `⌘Z` / `⌘⇧Z` | 撤销 / 重做 |
| `⌘X` / `⌘C` / `⌘V` | 剪切 / 复制 / 粘贴 |
| `⌥Backspace` / `⌥Delete` | 删除光标左侧 / 右侧单词 |
| `⌘Backspace` / `⌘Delete` | 删除至行首 / 行尾 |
| `⌘⇧K` | 删除当前行 |
| `⌘Enter` / `⌘⇧Enter` | 在下方 / 上方插入新行 |
| `⌥↑` / `⌥↓` | 上移 / 下移当前行 |
| `⌥⇧↑` / `⌥⇧↓` | 向上 / 向下复制当前行 |
| `⌃J` | 合并行 |
| `Tab` / `⇧Tab` | 插入缩进 / 取消缩进 |
| `⌘]` / `⌘[` | 增加 / 减少缩进 |
| `⌘/` | 切换行注释 |
| `⌘K`，再按 `⌘/` | 切换块注释 |

`Delete` 在这里指向前删除键，Mac 键盘通常使用 `Fn+Backspace`。编辑器提供注释操作，但应用仍按严格 JSON 规则校验，含注释的文档会显示语法错误。

`⌘C` 使用原生编辑器的复制行为；工具栏“复制”用于复制全文。对比工具栏的复制按钮已禁用，编辑区内仍可用 `⌘C` 复制选中文本。

## 光标、选区与多光标

| 快捷键 | 功能 |
|---|---|
| `←` / `→` / `↑` / `↓` | 移动光标 |
| `⌥←` / `⌥→` | 按单词移动 |
| `⌃⌥←` / `⌃⌥→` | 按子词移动 |
| `⌘←` / `⌘→` | 移到行首 / 行尾 |
| `⌘↑` / `⌘↓` | 移到文档开头 / 末尾 |
| `⌃↑` / `⌃↓` | 按段落移动（可能受系统快捷键占用影响） |
| `PageUp` / `PageDown` | 向上 / 向下移动一页 |
| 上述移动键加 `⇧` | 移动并扩展选区 |
| `⌘A` | 全选 |
| `⌘L` | 选择当前行 |
| `⌘D` | 选择下一个相同文本，添加选区 |
| `⌃⌘D` | 选择上一个相同文本，添加选区 |
| `⌘⇧L` 或 `⌘F2` | 选择全部相同文本 |
| `⌘⌥↑` / `⌘⌥↓` | 向上 / 向下添加光标 |
| `⌃⇧→` / `⌃⇧←` | 扩大 / 缩小结构选区 |
| `⌘U` / `⌘⇧U` | 撤销 / 重做选区变化 |

## 折叠与显示

以下是输入编辑器的快捷键。对比编辑器工具栏的折叠、展开和换行按钮仍按当前模式作用于双侧输入或差异预览。

| 快捷键 | 功能 |
|---|---|
| `⌘⌥[` / `⌘⌥]` | 折叠 / 展开当前位置 |
| `⌘K`，再按 `⌘L` | 切换当前位置折叠 |
| `⌘K`，再按 `⌘0` | 全部折叠 |
| `⌘K`，再按 `⌘J` | 全部展开 |
| `⌘K`，再按 `⌘[` / `⌘]` | 递归折叠 / 展开 |
| `⌘K`，再按 `⌘1`～`⌘9` | 折叠指定层级 |
| `⌘K`，再按 `Z` | 切换自动换行；对比输入模式下同步两侧 |
| `⌘;` | 切换当前编辑器的行号显示 |

## 侧栏与窗口

| 快捷键 | 功能 |
|---|---|
| `←` / `→` | 侧栏分隔条获得焦点后，每次缩窄 / 加宽 10 个逻辑像素 |
| `⌘W` | 关闭原生窗口，不是关闭当前标签 |
| `⌘M` | 最小化窗口 |
| `⌘H` | 隐藏应用 |
| `⌘Q` | 退出应用 |

窗口快捷键由 MyGo 的 macOS 默认菜单提供。
