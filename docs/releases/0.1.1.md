## 修复与改进

- 修复切换到对比标签页或切换对比模式时，工具栏按钮短暂变灰、闪烁的问题。按钮仅在实际处理 JSON 时显示忙碌状态。
- Windows 和 Linux 侧边栏顶部增加「JSONPal」标题，保留窗口拖动区域和折叠按钮；macOS 保留红绿灯布局。
- Windows 和 Linux 菜单栏常驻显示，提供中文「文件 / 编辑 / 帮助」菜单，可通过「帮助 → 关于 JSONPal」查看应用信息。
- macOS 菜单统一为中文，保留应用菜单、窗口菜单和系统快捷键；「JSONPal」和「帮助」菜单均提供关于入口。
- 关于窗口增加应用图标，Linux 额外显示作者信息。

## 下载与安装

- macOS：Intel 芯片选择 `mac-x64.dmg`，Apple Silicon 选择 `mac-arm64.dmg`；也提供 ZIP 压缩包。
- Windows：选择 `win-x64-setup.exe` 安装版，或 `win-x64-portable.exe` 便携版。
- Linux：选择 x64 架构的 AppImage 或 tar.gz。
