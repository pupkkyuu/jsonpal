# JSONPal · MyGo 原生 Demo

JSONPal 使用 Go / MyGo 原生编辑器和 Onevra 组件库，仅面向 macOS 开发环境。没有 Web 前端，也不需要 Node.js 或 Bun。

## 已实现

- 使用 Onevra `shells/sidebar.NewShell` 管理窗口、浮动标题栏、侧栏、底部工具栏及内容区域。
- 默认窗口为 1000 × 650，最小 760 × 400；侧栏使用 Shell 默认宽度 220，可收起/展开、拖动调宽、键盘调宽及双击恢复默认宽度。
- Shell 的 `Left`、`LeftToolbar`、`ContentTitle` 和 `Content` 插槽分别承载导航、设置入口、文档标题和工具栏、JSON 编辑区。
- 按钮、文本、侧栏项、图标和滚动容器使用 Onevra components；所有图标使用组件库提供的 Lucide 资源，图标按钮使用 Shell 的 `IconButton`。
- 界面使用 Onevra 默认调色板、字体和字重，主题初始为 `Auto`，跟随系统浅色/深色。设置可选择“明亮 / 夜晚 / 自动”，同时更新原生窗口外观和编辑器高亮。
- 启动时显示欢迎页，不自动创建或挂载编辑器。背景参考 Onevra Gallery 的 `welcomeIconField`，使用斜向 Lucide 图标、渐变染色与中心淡化，随明亮/夜晚主题切换；新建标签后进入对应编辑器。
- JSON 编辑器沿用 MyGo 原生编辑能力，语法高亮随 Shell 主题切换：浅色使用指定的 Monaco `vs` 配色，暗色使用 `vs-dark` 配色；背景、行号和选区继承 Shell 主题。Onevra 的 `components/code` 为只读代码展示，不替代可编辑 JSON 文档。
- 侧栏使用 `components.SidebarItem` 展示导航和标签，标签页标题使用 `SidebarSection`。点击“新建格式化”或按 `⌘N` 创建空标签，按顺序命名为“格式化 1、格式化 2……”，自动选中并聚焦编辑器；侧栏数量和顶部标题同步更新。
- “新建对比”创建“对比 1、对比 2……”标签，使用独立 `diffeditor` 包的编辑器实现。左右 JSON 输入区各自保留文档、撤销、选区、滚动、查找和防抖校验状态。
- 对比编辑器工具栏的“对比 JSON / 编辑 JSON”切换双侧输入和只读差异预览，复用原缓冲区，不自动格式化或排序。MyGo 原生并排差异视图显示红色删除、绿色新增、行内变化、同步滚动和上下差异导航，底部不显示状态栏。它比较原始文本，不进行 JSON 语义比较。
- 对比输入模式的格式化、压缩、转义、去转义、排序同时作用于两侧，空侧跳过；先计算两侧结果，任一侧失败时保留两侧原文并标记错误。对比工具栏的复制按钮在输入和预览模式均禁用；清空两侧可撤销，并返回左侧输入。
- 对比预览禁用文档变换，保留相同内容折叠/展开和工具栏换行。搜索切回最近使用的输入侧并打开其原生查找栏；两侧编辑后再次进入预览，差异按当前文本更新。
- 点击标签切换编辑器。标签仅保存导航信息和编辑器引用；每个编辑器独立管理内容、撤销/重做、选区、滚动位置、原生查找和校验状态，格式化与压缩仅作用于当前编辑器。
- 标签列表单独滚动，新建入口和标签数量固定可见；新建或选中的标签自动滚入视野。
- `Ctrl+Tab` / `Ctrl+Shift+Tab` 按侧栏顺序向后 / 向前循环切换标签，支持格式化和对比编辑器；设置面板打开时暂停切换。完整说明见[快捷键文档](docs/shortcuts.zh-CN.md)。
- `⌘B` 收起/展开侧边栏，保留其宽度；设置面板打开时暂停。有快捷键的按钮 tooltip 显示对应按键，编辑器提示随当前模式变化；原生查找栏也补充快捷键提示。
- 悬停标签时在右侧显示关闭按钮，移开后隐藏。关闭当前标签优先选择右侧邻居，没有右侧时选择左侧；关闭其他标签不切换编辑器。关闭最后一个标签自动创建空白编辑器，标签编号持续递增。
- 点击底部设置图标或按 `⌘,` 打开设置面板，沿用 Onevra Gallery 的 `Dialog` + `Settings` 结构，当前只有“外观 → 主题”。关闭按钮、Esc 或点击遮罩可返回编辑器；主题选择在当前会话内保留。
- 工具栏在空间不足时横向滚动，使所有按钮仍可访问。
- 通用工具栏顺序：格式化、压缩｜转义、去转义、字段排序｜全部折叠、全部展开、自动换行｜搜索、复制、清空，组间使用分隔线。
- 对比工具栏在通用按钮前显示“对比 / 编辑”切换，预览时在其前方显示“上一个差异、下一个差异”。
- 点击格式化图标或按 `⌘⇧F`，以 2 空格缩进格式化；只调整空白，保留字段顺序、数字原文与字符串转义。
- 文档变换及清空后光标回到文档开头，视图回到左上方；内容未变化、空输入或格式错误时也重置位置。
- 点击“压缩”移除 JSON 字符串外的多余空白，保留字段顺序、重复键、数字原文、字符串内容及转义。
- 点击“全部折叠 / 全部展开”，通过当前编辑器的原生折叠命令隐藏或恢复所有可折叠区域，包括嵌套对象和数组。折叠状态随编辑器保留，仅改变视图，不修改文本或新增撤销步骤；空文档及单行 JSON 无可折叠区域时保持原样。
- 点击“自动换行”切换当前编辑器的长行显示，开启时按钮显示主题背景；原生换行快捷键与按钮同步，切换标签后反映各自的状态，不修改文本、选区或撤销记录。
- “转义”把全文编码为带外层引号的 JSON 字符串，支持普通文本及空文本。“去转义”每次解除一层，支持带或不带外层引号的转义字符串；有效的非字符串 JSON 保持原样。解码后的普通文本仍按严格 JSON 规则显示诊断。
- “字段排序”按 UTF-16 字符串顺序递归排序对象字段，输出 2 空格缩进；保留数组顺序、重复键相对顺序、数字原文和字符串转义。
- “复制”通过当前窗口的剪贴板接口写入全文，保留原选区，可在其他编辑器或应用中粘贴。“清空”移除全文并清除诊断，可撤销/重做。所有文档变换均作为单次可撤销编辑提交，失败时保留原文本。
- “搜索”打开原生查找栏并聚焦查询输入，使用选中文本作为初始查询；Esc 关闭后返回编辑器。原生查找/替换、大小写、正则等行为保持默认。
- 格式化与压缩作为一次可撤销编辑；内容未变化时不新增撤销步骤，非法 JSON 和空输入保留原文本。结果记录在应用状态中，当前布局不展示底部结果提示；非法 JSON 通过编辑器诊断展示。
- JSON 实时校验采用 300 毫秒防抖，在后台执行，并通过 MyGo diagnostics 显示首个语法错误的淡红色行背景、红色波浪线、悬停提示和滚动条标记。输入时立即清除旧标记；旧版本校验结果不会覆盖新内容，结果通道与标签绑定，不会应用到其他标签。显式格式化或压缩立即校验，空文档不报错。校验采用严格 JSON 规则，注释仍会报错。
- 剪切、复制、粘贴、全选、撤销、重做由原生编辑器提供。

## 界面语言

当前只发布简体中文。应用文案使用 `locales/zh-Hans.json` 中的 ARB 消息；MyGo 内置编辑器菜单、查找状态和 Onevra 组件也使用同一窗口语言。自定义查找栏保留快捷键提示并显示中文。系统语言没有匹配项时回退到简体中文；JSON 解析器的原始错误详情保留原文。

修改消息后运行：

```bash
go tool mygo generate
go tool mygo i18n check
```

将语言目录和生成的 `locales/catalog_gen.go` 一同提交，因此普通 `go test` 和 `go build` 无需先生成。以后添加 `locales/en.json` 并生成即可复用类型化消息接口；当前没有语言切换设置。

## macOS 开发启动

需要 Go **1.27.1 或更高版本**。项目固定使用 MyGo **0.5.1** 和 Onevra 提交 **`315079ee0379`**（伪版本 `v0.2026.10-0.20261015042213-315079ee0379`），通过 `go.mod` 的 tool 指令运行 CLI，无需全局安装 MyGo。

```bash
go mod download
go tool mygo dev
```

首次运行会编译开发应用；窗口标题为 `JSONPal`。修改 Go 文件后开发进程重新编译并启动。退出应用或在终端按 `Ctrl+C` 停止。开发应用与缓存写入被 Git 忽略的 `.mygo/`。

Onevra 的该提交已适配 MyGo 0.5.1，版本固定后不会随主分支变化。待包含该提交的正式版本发布，显式升级 `github.com/oneo-me/onevra/source` 到对应版本，运行 `go mod tidy` 并完成回归检查。

环境检查：

```bash
go tool mygo doctor
```

仅供本机开发，也可以直接启动：

```bash
go run ./cmd/jsonpal
```

## 验证

```bash
go test ./...
go test -race ./...
go vet ./...
go tool mygo i18n check
go build -o build/jsonpal ./cmd/jsonpal
```

测试覆盖格式化/压缩结果、数字原文、Unicode 错误位置、非法输入保护，以及 MyGo 原生 UI 中的编辑、工具栏按钮、快捷键、撤销/重做，默认主题切换时的文档状态保留，以及窄工具栏滚动后首尾按钮的可访问性。工作区测试覆盖按钮/快捷键新建、切换后的独立撤销、选区/滚动/查找保留、标签列表自动滚动及通过接口承载其他编辑器。编辑器测试覆盖脱离工作区独立使用、防抖重置、过期结果丢弃、不同编辑器间的诊断隔离、错误波浪线与撤销后的诊断恢复。设置测试覆盖三种主题选项、关闭后的焦点/编辑状态恢复及窄窗口布局。

错误行背景与诊断共享版本保护：输入时清除旧标记，校验完成后更新，撤销后重新校验；只影响格式化编辑器与对比输入两侧。颜色跟随主题与高对比偏好，差异预览仍使用原有红绿标记。

## 工程结构

```text
cmd/
  jsonpal/
    main.go                 命令入口，只负责启动和错误退出
internal/
  desktop/                  原生桌面界面与工作区状态
    window.go               MyGo 生命周期与 Onevra Shell 创建
    app.go                  窗口状态、Shell 插槽和编辑器宿主
    welcome.go              启动欢迎页与图标背景
    tabs.go                 标签导航信息及编辑器创建/切换
    titlebar.go              文档标题及工具栏
    sidebar.go               工作区导航
    *_test.go                界面及交互测试
  editor/                    编辑器接口与实现，独立于标签
    editor.go                Editor 接口、视图选项及操作结果
    json.go                  单文档 JSON 编辑器状态与渲染
    actions.go               格式化、压缩及共用的文档更新流程
    folding.go               全部折叠与全部展开
    wrapping.go              原生自动换行切换
    search.go                原生查找栏入口
    shortcuts.go             工具栏快捷键提示
    findbar.go               沿用原生查找布局并补充快捷键提示
    theme.go                 JSON 浅色/暗色高亮
    diagnostics.go           防抖、后台校验调度与诊断适配
    *_test.go                编辑器独立使用及校验测试
  diffeditor/                独立双文档对比编辑器
    diff.go                  左右输入、模式切换和差异视图
    comparison.go            对比工具栏及差异导航
    actions.go               双侧原子变换及公共工具行为
    *_test.go                对比、视图状态及双侧操作测试
  setting/                   独立设置模块
    panel.go                 设置面板布局、打开状态及导航
    appearance.go            主题偏好、选择交互及变更回调
    *_test.go                设置面板独立使用测试
  jsondoc/                   不依赖 UI 的 JSON 处理
    format.go                保留字段和数字原文的格式化
    compact.go               保留文档数据的 JSON 压缩
    escape.go                全文转义及单层去转义
    sort.go                  保留原始数据的递归字段排序
    validate.go              严格 JSON 校验及错误定位
    *_test.go                格式化与校验测试
locales/                    中文 ARB 目录、生成的类型化接口及回退测试
docs/                       项目说明、历史功能和截图
mygo.json                   应用元信息及 main 入口配置
go.mod / go.sum             Go 依赖
TODO.md                     后续功能
```

采用 Go 的 `cmd` / `internal` 分层：入口调用 `desktop.Run`，桌面模块通过 `editor.Editor` 接口承载单文档 JSON 编辑器和独立包中的对比编辑器。`diffeditor` 复用 `editor.JSON` 管理两侧输入，纯 JSON 变换由 `jsondoc` 提供；JSON 处理不引用 MyGo 或 Onevra。编辑器拥有文档状态，标签只管理导航。独立的 `setting.Panel` 管理设置界面与偏好，桌面层通过回调应用主题变更。测试与被测包放在一起，只导出跨包使用的接口。后续组织规则见 [代码结构说明](docs/architecture.zh-CN.md)。

`mygo.json` 的 `main` 已设置为 `./cmd/jsonpal`，因此仍可在项目根目录运行 `go tool mygo dev`。

当前没有内容持久化，关闭窗口或开发热重启会丢失编辑内容。未添加发布打包、签名、公证、自动更新或 CI 配置；本轮不验证 Windows/Linux。

Onevra 组件库：[source](https://github.com/oneo-me/onevra)。

MyGo 文档：[安装与开发](https://mygo.egoist.dev/docs/getting-started#install)、[原生代码编辑器](https://mygo.egoist.dev/docs/ui/code-editor)。
